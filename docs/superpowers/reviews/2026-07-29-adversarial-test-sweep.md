| `bun run lint`           | Pass; no findings                                                                  |

The eight skips are the endpoint-gated cases in `e2e/s3-minio.e2e.spec.ts`.
They are expected when `S3_E2E_ENDPOINT` is unset, but they remain visible here
and must run without skips against the dedicated MinIO container later in the
sweep. The supplied baseline took about 4.24s; the fresh ordinary run took
3.93s with identical counts, a normal wall-clock variation.

## Bounded scope

This sweep covers local unit and end-to-end tests, temporary filesystem and
SQLite state, mocked GCS behavior, and the S3 path against the Docker MinIO
image pinned in CI. New stress cases stay bounded by the design: at most 32
clients, 8 MiB per request, 64 MiB of aggregate live payload, a 10-second case
timeout, and 20 repetitions for race-sensitive cases. The existing 140 MiB
upload test remains as the one distinct check above Bun's default body limit;
it is not part of the repeated stress runs. Docker cases have a 60-second cap.

It does not contact live AWS or Google Cloud services, attempt unbounded
resource exhaustion, perform destructive operations on the host, or add
synthetic stress beyond that bounded contention and repetition. Permission
faults or other cases that depend on changing host-wide state are excluded when
an isolated temporary-directory test cannot reproduce them safely.

## Initial risk dispositions

The labels below distinguish current evidence from planned work:

- **Covered:** an existing test protects the material contract.
- **Later:** a focused case or bounded repeat is assigned to a later sweep task.
- **Excluded:** the case is outside the bounded environment, with the reason stated.
- **No added test:** another test would add no distinct failure signal.

## Full-sweep completion criteria

1. `bun test`, `bun run format --check`, `bun run lint`, and
   `bun run typecheck` are clean, and the final diff has no formatting errors.
2. The ordinary suite has no unexplained skips or failures. The eight
   endpoint-gated MinIO skips remain explicit locally, while the dedicated
   Docker MinIO run executes the full file with zero skips.
3. Every production bug found has a focused regression that was observed
   failing for the expected reason before the smallest fix made it pass.
4. Race-sensitive local and MinIO cases pass all 20 bounded repetitions without
   intermittent status, integrity, count, or timeout failures.
5. Coverage is reviewed after the sweep for meaningful contract gaps. A
   percentage increase is not a target, and every important uncovered path is
   either tested or given a concrete bounded-scope rationale.
